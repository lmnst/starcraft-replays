内置策略 vs LLM 高层指挥

同一个 bot、同样的对手和地图，分两组各打一局：代码组完全由 bot 自己决定；LLM 组由大模型定期查看局面，决定要不要接管部队姿态、发展重点、兵种和侦察，没接管的部分仍由 bot 自己打。下面三局各有回放、数据和 LLM 的每一步决策。

回放

游戏画面：用打这一局的同一个引擎（OpenBWData.dll，和服务器对局逐字节相同）重放录像并渲染成视频，镜头自动跟随交战，无战争迷雾。全图战术图：同一引擎导出的所有单位位置。两者都和对局日志逐 240 帧核对过双方各兵种数量。1× 等于"最快"游戏速度。切换两组时停在同一时刻；点图表或下面任意一条 LLM 决策，回放跳到那一刻。
